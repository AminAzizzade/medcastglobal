# Backend

Bu klasör gelecekteki sunucu uygulaması için ayrılmıştır. Henüz bir backend, API, veritabanı veya kullanıcı girişi uygulanmamıştır.

Teknoloji ve ihtiyaçlar belirlendiğinde sunucu kodu, bağımlılıkları, ortam değişkenleri için örnek dosya ve çalıştırma talimatları burada tutulabilir. Şifreler ve gerçek erişim anahtarları depoya eklenmemelidir.
